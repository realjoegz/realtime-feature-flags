# Evidence

Each row states a claim and links the tests that check it. `npm run verify` runs `scripts/check-claims.mjs` after the tests, and it fails unless every linked test ran and passed in that run.

A test whose name ends in "(seed S, N runs)" runs fast-check with that seed and that number of runs. A control test runs the same property against a committed broken evaluator in `packages/core/test/controls/` and passes only when the property fails there.
